# Day 1 – Dataset Exploration

## Objective
Explore the Iris dataset using Python and NumPy to understand its structure, features, target labels, and category distribution.

## Concepts Learned
- Loading a dataset using Scikit-learn.
- Understanding features and target variables.
- Accessing feature names and target names.
- Understanding unique values.
- Counting category occurrences using NumPy's `unique()` function.
- Iterating through values using `zip()`.

## Dataset
Iris dataset – a classification dataset containing three flower categories.

## Key Learning
Understood how to inspect a dataset before beginning machine learning model development.

## Tools Used
- Python
- NumPy
- Scikit-learn
